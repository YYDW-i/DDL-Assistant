# 今日计划与提醒更新实施方案

目标：保留现有数据，修复亮色选中可读性，新增独立一日计划，默认提前72/24/3小时提醒。

用户已确认：今日计划可勾选导入已有今日任务、安排时间、AI生成完整任务并预览确认；移出计划不删除原任务。

设计：
- 今日计划单独保存日期、任务引用及计划开始时间，不复制导入的任务，不改已有截止时间；可查看历史/次日计划。
- AI生成沿用现有工作线程和确认流程，补齐工作量、提醒等属性，确认时任务与计划一并原子保存。
- 新建数据表采用加法迁移，迁移前自动备份；旧任务及自定义提醒完整保留。
- 默认提醒采用相对截止时间的72/24/3小时；已有None默认规则随新版本生效，明确的自定义时间不变。错过多个默认提醒时合并一次补发，后续时点继续生效。

4. [ ] 今日计划表、v4迁移、服务事务/唯一性/移出不删除/历史隔离测试。
